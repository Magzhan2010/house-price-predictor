# House Price Predictor 🏠

Welcome to my repository! This is **my very first Machine Learning model** built from scratch. 

The project uses a **Linear Regression** algorithm to predict estimated apartment prices based on their size in square meters.

---

## 🚀 Project Overview
This is a beginner-friendly data science project designed to demonstrate the fundamentals of predictive modeling. It takes historical real estate data (square meters and prices) to find a linear relationship and estimate the cost of any apartment.

## 🛠️ Tech Stack
* **Python** (Core language)
* **Pandas** (Data manipulation and analysis)
* **Scikit-Learn** (Machine Learning library - `LinearRegression`)
* **NumPy** (Array formatting)
